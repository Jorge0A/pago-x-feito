# v0 plan — Reliable records (approved 14/11/2026)

## Layout
apps/web (Next.js App Router, Tailwind, shadcn/ui, PWA) · packages/core (domain logic, Vitest) ·
packages/db (Supabase migrations, types, seed) · packages/extractors (Anthropic + fixtures) ·
docs/ · .github/workflows (CI).

Background work without extra services: extraction runs in a route handler right after upload;
the daily Vercel cron sweeps stuck items and sends the digest. Managed queue in v1.

## Data model decisions
Full v0 schema in the first migration (no schema changes inside v0 without asking).
Added to the spec: `task_dependencies` join table, `ai_calls` cost log, `reminder_settings`.
Money bigint centavos; due dates `date`; moments `timestamptz`. `budget_lines.contract_id` optional.
`documents.building_id` nullable for v1. `events` append-only by trigger + revoke. RLS via
`obra_members`; buildings readable by members of any obra in them.

Payments not assigned to a budget line count at obra level only ("não alocado") so the centavo
match with the bank stays honest.
